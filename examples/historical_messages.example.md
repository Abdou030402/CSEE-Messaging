# Real Examples — CSEE Historical Messages (SANITIZED EXAMPLE)

These are style/tone references for drafting. This committed file is **sanitized** —
all names, emails, phone numbers, and links are placeholders.

For best results locally, copy this to `historical_messages.md` (which is gitignored)
and paste in your real past messages:

    cp examples/historical_messages.example.md examples/historical_messages.md

`draft_message.py` uses `historical_messages.md` if it exists, otherwise this example.
